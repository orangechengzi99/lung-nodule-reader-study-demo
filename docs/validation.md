| 依赖一致性 | `pip check` 通过 |
| unittest | 共 62 个测试方法，61 通过、1 个因 Windows 符号链接权限跳过，无失败或错误 |
| 默认流程 | 三项默认种子、5000 次 bootstrap，四步成功，23 项数据质控通过 |

## 重新验证

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
.\.venv\Scripts\python.exe run_all.py
```

检查新运行目录中 `run_manifest.json` 的 `status=success`、四步退出码均为 0、`quality_checks` 为 23/23；复核结果报告、六图与工作簿。默认运行的 14 份 CSV 应与预计算样例一致；自定义种子后不要求一致。测试和完整运行互补，基线一致并不是唯一正确性依据。
