# 统一运行入口

## 使用方法

先选择 Python 解释器并按项目首页安装运行依赖。测试使用标准库 unittest，无新增测试框架。实测环境与验收范围见[验收摘要](validation.md)。

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe run_all.py --output outputs/demo
```

不指定 `--output` 时，自动新建 `outputs/run-时间戳/`。每次生成完整的新数据，不读取作品中已有的结果。统一入口依次执行模拟、描述分析、FROC、教学推断，并使用与入口相同的 Python 解释器。

若从其他目录启动，请传入 `run_all.py` 的完整路径；相对的 `--output` 始终以项目根目录为基准，不以终端当前目录为基准。

## 输出与保护

一次运行的目录内容：

```text
outputs/demo/
├─ data/                 # 7 份模拟 CSV
├─ results/              # 7 份结果 CSV、2 份说明、6 张图
├─ workbooks/            # 综合 Excel 工作簿
├─ logs/                 # 每个脚本各一份标准输出/错误日志
├─ .cache/matplotlib/    # 本次绘图缓存，不是分析产物
└─ run_manifest.json     # 参数、环境、文件摘要与运行状态
```

只接受尚不存在的运行目录，即使原目录为空也不覆盖；没有强制覆盖开关。重复运行请换目录名称或不传 `--output`。项目内部仅允许 `outputs/` 下的新子目录，拒绝项目根目录、其上级、代码/测试/文档/基线目录；支持项目外的新目录及中文、空格路径。规范化后的路径用于检查，Windows 符号链接的安全用例在本账户下因权限不足跳过，未将其标为实测通过。

直接运行原四个脚本仍保留旧行为，会写入 `03_模拟数据`、`04_分析结果` 和 `05_综合结果`。日常复现推荐统一入口。复制单个分析脚本练习时，需要同时复制同目录的 `study_config.py`，绘图脚本还需要 `plot_style.py`，否则缺少公共模块。

## 参数

| 参数 | 默认值 | 用途 |
|---|---|---|
| `--output` | 时间命名的新目录 | 隔离本次全部生成文件 |
| `--simulation-seed` | 20260920 | 模拟病例和阅片结果 |
| `--sequence-seed` | 20260921 | AB/BA 平衡分配 |
| `--bootstrap-seed` | 20260923 | 阅片者/病例重抽样 |
| `--bootstrap-iterations` | 5000 | 重抽次数，至少 2 |
| `--plot-language` | auto | 中文字体可用则中文，否则英文；可指定 zh/en |

种子必须是非负整数。以下仅用于快速调试，不能拿 30 次重抽的区间替代默认结果：

```powershell
python run_all.py --output outputs/debug-01 --simulation-seed 11 --sequence-seed 12 --bootstrap-seed 13 --bootstrap-iterations 30
python run_all.py --help
```

默认教学公式、两条件配对、预设候选匹配和探索性推断边界均未改动。参数通过子进程专用环境传递，不修改用户终端的环境。

`auto` 检查实际图中文字所需的字符覆盖，先选本机微软雅黑或已登记的常见中文字体；没有合适字体则用 Matplotlib 自带字体及英文图中文字。`en` 强制英文；`zh` 要求中文字体，无可用字体时明确失败，避免输出方框字。该参数只影响绘图，不翻译 CSV、Excel 或中文报告。实际字体/语言会写入对应步骤日志和清单的 `plot_style`。

## 运行记录与失败定位

`run_manifest.json` 包含三项种子、重抽次数、请求绘图语言、实际字体/语言、解释器路径/版本、系统及四个直接依赖版本，入口/两个公共模块/四脚本的 SHA256，以及模拟输入和分析产物的相对路径、大小、SHA256。CSV 另记录列名、数据行数；记录四步命令、退出码、耗时、日志路径和 23 项质控状态。

状态为 `running`、`success` 或 `failed`。只有四步均成功、7 份输入和 16 份分析产物齐全、23 项质控均通过才标记成功。成功退出码 0；流程失败为 1；参数/输出路径错误为 2。任一步失败即停止，不运行后续脚本；已生成的文件保留供排查，不自动删除或覆盖。

缺依赖时，查看终端信息，用运行入口的同一解释器安装依赖。脚本失败时，优先查看清单对应的 `stderr_log`，再看 `stdout_log`。参数或目录错误发生在运行目录创建前，不生成清单；断电、强制结束等不能保证写出最终失败状态，此时清单可能仍为 `running`。

清单不记录全部环境变量，但含本机解释器/目录等绝对路径；日志也可能包含本机路径。公开前需审查，不默认把全部运行目录上传。

## 验证范围

当前 62 个测试方法在 Windows / Python 3.14.5 环境中为 61 通过、1 个符号链接权限用例跳过。默认 5000 次流程与低次数边界调试均成功，各 23 项质控通过；默认 14 份 CSV 与预计算样例字节一致。低次数结果不用于统计解释。

完整验证结果与历史环境组合见[软件验证结果](validation.md)。方案文件清单、预设匹配关系和绘图语言说明见[方案代码配套说明](protocol-code-amendment.md)。
