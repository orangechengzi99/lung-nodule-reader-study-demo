## 附件 D 推荐运行方式

先按项目首页创建环境并安装依赖，再在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe run_all.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
```

统一入口默认 5000 次重抽样，自动创建时间命名目录；相对输出路径以项目根目录为基准。直接逐个运行四个脚本会覆盖 `03_模拟数据`、`04_分析结果` 和 `05_综合结果`；日常复现应使用统一入口，避免覆盖预计算样例。

生成的 FROC Excel 首行无穷大阈值为文本 `inf`；CSV 的 `inf` 与 V2.0 数值基线一致。

## 附件 A FROC 实现范围

附件 A 的 FROC 分析使用以下预设匹配示例：

> 使用 5 例虚构扫描、6 个参考结节和 13 个候选的预设候选—参考 ID 匹配关系，演示置信阈值筛选、重复检出处理、结节级敏感度与 FP/scan 计算，并绘制 FROC。

输入表已经提供匹配 ID。代码检查 ID 是否存在、是否属于同一扫描，按阈值保留候选；同一参考结节的多个候选仅计一个 TP，剩余计 FP。没有 CT 图像、候选三维坐标、分割轮廓或距离/重叠匹配算法。原方案关于真实空间匹配的设计内容是未来研究要求，不是本项目已实现功能。

## 图表语言说明补充

内部字段与分类编码保留英文，报告以中文为主；图表 `auto` 模式在本机中文字体覆盖足够时使用中文，否则回退英文，可用 `--plot-language en` 强制英文。该参数不翻译 CSV、报告或 Excel。请求 `zh` 而无可用中文字体时明确失败，不输出方框字图表。
