# MRMC辅助阅片描述性结果说明

## 数据与设计

本教学练习包含8名虚构阅片者、80例虚构胸部CT，以及无AI和AI辅助两种阅片条件，共1280条阅片者-病例-条件记录。80例CT中包含48例结节阳性病例、32例结节阴性病例和66个参考结节。

所有数据均为固定随机种子生成的虚构数据，不来源于真实患者、医院或AI产品。

## 数据质控

共23项预设数据质量检查，全部通过。检查范围包括：

1. 阅片者编号和病例编号唯一。
2. 阅片者-病例-条件记录无重复、无缺失。
3. 每个阅片者对每个病例均具有无AI和AI辅助两种结果。
4. AB/BA序列分配平衡，条件与周期对应关系正确。
5. 病例级判断符合统一的预设标记规则。
6. 每条记录均满足`TP + FN = 参考结节数`，且计数非负。

## 主要描述性结果

| 指标 | 无AI | AI辅助 | AI辅助减无AI |
| --- | ---: | ---: | ---: |
| 阅片者平均结节级敏感度 | 77.5% | 83.7% | +6.3个百分点 |
| 阅片者平均`FP/scan` | 0.51 | 0.68 | +0.17 |
| 阅片者平均病例级敏感度 | 91.4% | 93.2% | +1.8个百分点 |
| 阅片者平均病例级特异度 | 60.9% | 49.2% | -11.7个百分点 |
| 阅片者平均阅片时间 | 4.82分钟 | 4.12分钟 | -0.70分钟 |
| 阅片者平均阅片信心评分 | 3.32 | 3.70 | +0.38 |

## 结果解释

在本组虚构数据中，AI辅助条件下阅片者平均结节级敏感度较高，平均阅片时间较短，但`FP/scan`较高，病例级特异度较低。这说明评价辅助阅片产品时，不能只看检出能力，还需要同时考虑误报负担和工作效率。

以上差值均为描述性结果，本节不据此判断统计学意义。项目另使用阅片者－病例双重Bootstrap演示标准误、95%置信区间和探索性P值，详见`MRMC教学性推断结果说明.md`；该教学性推断仍不能替代正式MRMC主分析，也不能证明真实AI产品具有临床有效性或临床获益。
